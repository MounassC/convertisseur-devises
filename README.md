# Convertisseur de devises

Application React qui convertit des montants entre le franc CFA (XOF), l'euro et le dollar, à partir des taux d'une API.

## Technologies

React, Vite, JavaScript, API REST (open.er-api.com)

## Fonctionnalités

- Conversion entre XOF, EUR et USD
- Inversion des devises en un clic
- Messages de chargement et d'erreur

## Lancer le projet

```bash
npm install
npm run dev
```

## Source des taux

[Rates By Exchange Rate API](https://www.exchangerate-api.com)
